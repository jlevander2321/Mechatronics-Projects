# Python Scripts

Modbus logging and PLC data analysis scripts.

## Environment
- Python 3.13.7 (64-bit), run from IDLE (Python 3.13)
- pymodbus 3.16.2: Modbus TCP client for OpenPLC and the CLICK PLUS
- matplotlib 3.11.2: plots of logged PLC data

Install the libraries with Python 3.13's own pip:

```
"C:\Users\<user>\AppData\Local\Programs\Python\Python313\python.exe" -m pip install pymodbus matplotlib
```

Run scripts from IDLE (F5).
